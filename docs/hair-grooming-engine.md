# Hair & Grooming Engine

这是中性、通用的职业修饰引擎，不按性别套用发型。

## 不可改变

发型、修剪轮廓、发际线、长度、颜色和可信密度。发际线变化是 hard failure。

## 可调整

在真实范围内增加 10–20% 可见发量；提供适度 root lift、自然 crown/side fullness、柔和发丝分离和少量自然碎发。Founder Studio 可比高管风格保留更多自然移动；Boardroom 的 grooming formality 最高。

## 审核

检查自然发量、发根支撑、真实密度、发际线保持、不扁塌和无假发感。扁塌记录 `flat_hair`；过度体积记录 `hair_volume_exaggerated`；光亮头套、头盔轮廓或融化边缘必须淘汰。

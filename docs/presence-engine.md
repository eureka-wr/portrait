# Presence Engine

Presence 不是把人物做得严厉，而是让画面中的人显得完整、稳定、可信且值得注意。

## 参数

- groundedness：身体和视线是否稳定落地。
- composure：面部、肩颈与构图是否克制。
- authority：是否具备承担决策的视觉分量。
- clarity：画面意图和眼神是否清晰。
- credibility：是否真实可信。
- visualWeight：主体在画面空间中的重量。
- agency：是否显得能发起行动和完成决定。
- approachability / openness：是否可接近、愿意协作。

四种 DNA 的权重必须不同。Boardroom 的 authority/groundedness 高于 Quiet Executive；Global Professional 强调 openness、credibility 与 approachability；Founder Studio 强调 agency 和 creativity。

## 审核

通过条件：`grounded`、`credible`、`professionally_substantial`、`emotionally_stable`、`memorable_without_theatricality`。

存在感不足通常表现为目光游移、肩膀收缩、头部漂浮、表情空白、人物在画面中视觉重量过轻。不能通过加深阴影、皱眉、僵硬站姿或过度锐化来伪造 Presence。

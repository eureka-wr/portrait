# CATV 职业肖像运营手册

## 创建一单

进入“全部订单”后点“创建订单”。填写客户昵称、渠道、付款状态、价格、客户要求和必要备注。联系方式只写找到这次会话所需的线索，不保存平台密码或敏感凭证。

## 检查客户照片

只接受 JPG、PNG、WebP。建议单人、脸部清晰、没有明显遮挡和重度美颜。系统的 Mock Analyzer 只能做技术占位，必须由人确认：只有一个主要人物、五官清楚、曝光正常、照片没有损坏。

## 选择风格

- 从容领导力：极简科技、高智感、安静自信。
- 国际职业形象：可信亲和、现代办公、适合合作场景。
- 高管领导力：沉稳权威、经典布光、年度报告感。
- 创业者工作室：聪明好奇、自然松弛、轻环境感。

风格是客户或运营人员主动选择，不根据脸推断职业。

## 复制 Prompt 与手工生成

在订单工作台点“编译 Prompt”，再点“复制完整 Prompt”。把客户原图与 Prompt 提交到有授权的外部图像编辑工具。生成后在“或使用外部工具”区域上传结果，备注工具和模型即可，不要填写外部 API Key、账号密码或私有链接。

## 自动生成

选择 Mock 或已配置的真实 Provider，点击“生成 4 张候选”。不要重复点击。任务超时、部分成功或失败时，成功图片会保留，提示会说明能否重试。

## 筛选候选

逐张展开 Pose / Gaze / Presence / Hair 清单。自动分数只作参考；命中 hard failure 必须淘汰并选择结构化原因。

### 如何判断眼神太柔或过凶

太柔通常是眼神游移、缺少对焦、上眼睑与嘴角一起显得犹豫；记录 `gaze_too_soft` 或 `gaze_timid`。过凶通常是用力瞪视、眉间紧张、眼白暴露异常或光线把凝视做得压迫；记录 `gaze_aggressive`。自然稳定的眼神能直视镜头但不会像盯人。

### 如何判断存在感不足

观察目光、头肩和画面重量是否同时稳定。肩膀收缩、头部漂浮、表情空白或人物在画面中“站不住”都属于 `weak_presence`。不能靠加深阴影或皱眉补救。

### 如何判断像证件照或继承原图姿势

完全正对、双肩齐平僵直、居中紧贴背景且没有商业构图层次，记录 `passport_photo_composition`。若成片保留原自拍俯角、头歪、身体侧倒、耸肩或镜头畸变，记录 `pose_inherited_from_source`。

### 如何判断头发太塌或像假发

头皮附近无发根支撑、顶部贴头且侧面失去自然厚度，记录 `flat_hair`。边缘融化、发丝像光滑整块材质、轮廓像头盔、体积完全对称或发际线变化，记录 `wig_like_hair` / `hairline_changed`；发际线变化必须淘汰。

### 何时淘汰、重做和记录反馈

身份明显变化、发际线变化、严重头歪、复制原图姿势、眼睛异常放大、严重怯弱/攻击性凝视、假发、证件照、服装畸形或塑料皮肤立即淘汰。方向正确但轻微肩膀、表情或发量问题可基于选中候选做单点微调。每次淘汰选择最具体原因；客户选择后记录最像本人、存在感、眼神、姿态、头发、服装和背景等正负原因，不把信息只留在自由文本。

## 发送两张预览

必须正好选择两张。点“下载两张并标记已发送”，系统输出小尺寸 JPG 和单处半透明预览标识。可以复制沟通文案后，通过小红书或微信人工发送。

## 记录客户选择

收到回复后，在“记录客户选择”选择预览 1 或 2，记录理由和客户原话。最终只能选一张，且必须来自已发送预览。

## 微调与高清导出

只在确有需要时写小幅微调，例如“肩膀略放松，其他全部保持”。不要让微调重新解释整张照片。确认最终图后导出 ZIP；检查其中的高清 JPG、PNG、1:1、4:5、简历、白底画布和压缩版。高清文件不应有水印、Logo、文字或边框。

## 完成与删除

确认客户已收到文件，再标记完成。完成后开始 7 天图片保留倒计时。客户要求提前删除时，使用“删除全部人像资产”；这会物理删除图片，但保留必要订单、反馈和审计。

## 常见失败

- 格式错误：让客户发送原始 JPG/PNG/WebP，不要截图成奇怪格式。
- 图片太小或模糊：请客户补一张短边至少 480px 的清晰照片。
- 多人照片：请客户提供单人图。
- Provider 未配置：切回 Mock，或复制 Prompt 走手工生成。
- 只返回两张：先审核成功结果，再补生成剩余候选。
- 超时：确认任务已停止后重试一次，不要无限点击。
- 质量失败：人工查看 hard failure；必要时淘汰并单张补生成。
- 存储失败：不要重复收费或重复调用模型，先确认任务提示再重试。
- 图片已过期：需要客户重新发送，系统不会从已删除资产恢复。
